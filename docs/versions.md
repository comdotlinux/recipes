# Verified versions

Every dependency version in this repository was checked at its release page on the day it was pinned. The evidence, with source links and dates, is kept per area:

- [Client: Kotlin, Compose Multiplatform, Gradle, Android](versions/client.md)
- [Backend: Workers tooling and libraries](versions/backend.md)
- Toolchain pinned in `mise.toml` (bun, node, Cloudflare `cf` CLI, JDK, maestro, gitleaks): see [spike S1](spikes/S1-toolchain.md)

Rule: a version is changed only together with its entry in these files.
