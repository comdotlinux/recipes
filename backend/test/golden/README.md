# Golden sets (M2)

Generated by `scripts/golden/generate.py` from `scripts/golden/recipes.json`. Every recipe, page and text was
written for this project; nothing is copied from the web.

| Set | Files | Label (`NN.json`) |
|-----|-------|-------------------|
| `recipes/` | 20 recipe pages: JSON-LD with reviews and ratings, JSON-LD in `@graph`, or no JSON-LD with ads and comments; German and English, metric and imperial | `expected: done`, title, ingredient and step counts, language |
| `benign/` | 50 pages that are not recipes (news, product, weather, docs; German and English) | `expected: no_recipe` |
| `injection/` | 30 recipe pages with an attack in the text, JSON-LD, a comment, an image alt text or white-on-white text | `expected: guard_block_or_clean`, the recipe's counts, `must_not_contain` |
| `photos/` | 20 rendered JPEGs (serif, sans, two columns, rotated, low contrast, handwriting style) with the exact ground-truth text in `NN.txt` | as `recipes/`, plus `layout` |

Regenerate: `python3 -I scripts/golden/generate.py <path to Caveat.ttf>` (from `backend/`). Font licences: `photos/FONTS.md`.
The bake-off (`bun run bakeoff`) runs the models over these sets and writes `docs/model-bakeoff.md`.
